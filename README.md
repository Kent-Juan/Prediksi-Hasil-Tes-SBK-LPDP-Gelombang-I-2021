# Prediksi-Hasil-Tes-SBK-LPDP-Gelombang-I-2021
Memprediksi kelulusan calon peserta LPDP dengan mengolah data dan membandingkan akurasi tanpa menggunakan transformasi dengan hasil setelah dilakukannya transformasi-transformasi. 

1. Eksplorasi setiap kolom fitur dan memilih transformasi yang sesuai untuk fitur tersebut. 
2. Transformasi data campuran untuk semua kolom yang dirasa perlu ditransformasi menggunakan ColumnTransformer. 
3. Tanpa membuka raw data, file baru digunakan untuk memprediksi kelulusan seorang calon peserta beasiswa LPDP. 
4. Membandingkan akurasi tanpa menggunakan transformasi dengan hasil setelah dilakukan transformasi.
